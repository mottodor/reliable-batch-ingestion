# BI-100 — Remove the archived pre-rewrite Git history

## Authorization

The project owner explicitly confirmed that no external consumer depends on the pre-BI-099 branch tip and requested that the old commit variation not be retained.

## Scope

- remove annotated tag `archive/pre-bi099-history`;
- expire all local reflogs that can retain superseded rebase commits;
- prune unreachable Git objects immediately;
- preserve the current rewritten `main` history and tree exactly;
- keep historical audit and worklog text unchanged as records of what was evaluated at the time;
- update only the current state and append-only worklog with the owner's superseding retention decision.

No product code, test behavior, dependency, configuration, contract, ADR, or delivery semantics may change.

## Irreversibility

After tag deletion, reflog expiration, and `git gc --prune=now`, old commit IDs that are unique to the pre-rewrite history cannot be reconstructed from this repository. Historical documents may still display those IDs as evidence identifiers, but Git commands in this repository will no longer resolve them.

## Procedure

1. Record the current rewritten `main` commit and tree.
2. Delete only `refs/tags/archive/pre-bi099-history`.
3. Expire all reflogs with an immediate cutoff.
4. Run immediate garbage collection and pruning.
5. Prove that the old tip and representative old audit candidates are absent from the object database.
6. Prove that current `main` remains linear and retains the recorded tree.
7. Synchronize terminal backlog/state/worklog and run the repository gates.

## Acceptance

- no Git ref points to the archived pre-rewrite history;
- local reflogs are empty after final cleanup;
- old unique commit IDs `c6d4b1537b3deeda0d5d1568db97a27394dfd207`, `5ee3781f8955e109b6890b117b9070fdd718ad5b`, and `a4ef6d34fad5629c992385c26ede74a12b937563` do not resolve as Git objects;
- rewritten `main` remains linear and its pre-BI-100 commit/tree are unchanged;
- current documentation distinguishes historical SHA text from locally resolvable objects;
- repository policy, lint, offline tests, and full verification pass.

## Result

- Deleted annotated tag `archive/pre-bi099-history`; `refs/heads/main` is the only remaining ref.
- Expired all 106 pre-cleanup reflog entries and ran `git gc --prune=now`.
- Confirmed that old unique commits `c6d4b1537b3deeda0d5d1568db97a27394dfd207`, `5ee3781f8955e109b6890b117b9070fdd718ad5b`, and `a4ef6d34fad5629c992385c26ede74a12b937563` no longer resolve.
- Preserved pre-BI-100 commit `0c85343b3318ad0375ce5a6b2547f65f92203b81` and tree `ab24eb3895e9a01137e9aa82e6cb52c40796e668` unchanged as the parent of BI-100.
- Confirmed linear `main`, a clean full `git fsck`, and no product/runtime file changes.
